# Game Brief: Ночная смена (рабочее название)

<!-- Jam: "Out of Control" · solo · 4 hours · Unity 6.3 LTS · Windows. Engine lives in project.yaml. -->

**One-sentence pitch:** Tower defense на схеме корпоративной сети: днём инженер ИБ строит топологию и расставляет СЗИ, ночью отбивает атаки, которые с каждой сменой всё меньше похожи на человеческие, пока сеть не начинает жить своей жизнью.

## Core loop
- **День** — читаешь почту офицеров ИБ (сюжет), на кредиты покупаешь ноды и СЗИ, ставишь их на сетку и соединяешь связями мышью.
- **Ночь (5–7 мин)** — серверы приносят кредиты; атаки-пакеты идут от интернет-шлюза по связям к Ядру; СЗИ сами детектят и режут, ты вбиваешь экстренные команды в терминал.
- **Утро** — отчёт смены (заработано / пропущено / потери), затем следующий день.

## Player goal & fail state — what "working" looks like
- Цель: продержаться 5 ночей. Пропущенные атаки снижают целостность Ядра; 0% → «Вы уволены» (game over).
- Финал ночи 5: сеть выходит из-под контроля; последняя доступная команда `shutdown --all` — игрок выдёргивает рубильник (концовка).

## MVP — what must exist to be the game
1. Карта сети: ноды Шлюз / Сервер (доход) / Ядро; днём — постановка и соединение за кредиты.
2. Ночная симуляция: пакеты идут по графу к Ядру кратчайшим путём, доход тикает.
3. 3 СЗИ, апгрейд до ур. 2: Firewall (блокирует % пакетов), IDS (раскрывает скрытые атаки и замедляет), Honeypot (перетягивает атаки на себя).
4. Терминал: `help`, `isolate <node>` (разорвать связи на N с), `scan` (показать скрытые пакеты), `patch <node>` (вылечить ноду); у команд кулдауны.
5. 5 ночей из данных, атаки нарастают: скан → брутфорс → DDoS → червь (заражает соседей) → аномалия (прыгает по несуществующим связям, порождает чужие ноды).
6. «Out of Control» по нарастающей: ночи 3–4 — в сети появляются ноды, которые ты не ставил; ночи 4–5 — инструменты сбоят (команда иногда бьёт не туда, UI глитчит). Сюжет — письма между ночами и реплики в логе.
7. 3D-комната: фиксированная камера на стол с монитором, игра на экране монитора (строится последней, режется первой).

## Out of scope — not building this
- Сохранения, мультиплеер, меню настроек, озвучка.
- Ходьба по 3D-комнате; процедурная генерация сети; больше 3 типов СЗИ.
- Реалистичная сетевая модель — IP и порты только антураж.
- Внешние ассеты — только примитивы, шрифт и процедурные эффекты.

## Build order
1. Ядро симуляции на чистом C# (граф, пакеты, СЗИ, экономика, парсер команд) + тесты `dotnet test` без Unity.
2. Unity: отрисовка карты и пакетов, одна играбельная ночь на фиксированной сети — первый тест в редакторе.
3. День: покупка / постановка / соединение нод, переход день ↔ ночь, отладочное ускорение ×4.
4. Терминал и команды.
5. Данные 5 ночей, типы атак, чужие ноды и глитчи.
6. Письма, лог-реплики, экраны отчёта / поражения / финала.
7. 3D-комната, эмбиент, полировка.
